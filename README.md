# Survey-Conduct
The Survey Conduct Analyzer is a lightweight and efficient tool designed to analyze text-based survey responses and generate both complete and custom reports. It simplifies the process of collecting, processing, and visualizing responses from structured surveys, making it ideal for research teams, educators, and social impact projects. 

🔍 Key Features
📄 Survey File Upload
Upload .xlsx survey response files with structured formats (e.g., one sheet per topic, question-answer column pairs).

📊 Custom & Complete Report Generation
Generate full reports with all survey responses or filter specific questions for customized insights.

📈 Response Visualization
Creates graphical reports (bar plots, frequency charts) for quick understanding of response trends.

🧾 Textual Analysis
Aggregates and summarizes user responses for each question in a clean, readable format.

🧑‍💼 User-Friendly Interface
Minimal, browser-based UI with clear prompts to upload files and download reports.

🧠 Ideal For
Academic surveys and feedback forms

Research-based questionnaire analysis

NGO/social work survey documentation

Institutional course or event feedback

📦 Tech Stack
Backend: Python (Flask)

Data Handling: Pandas, Openpyxl

Report Generation: python-docx, matplotlib, seaborn

Frontend: HTML, Bootstrap (or similar)

📁 How It Works
Upload your Excel file containing survey responses

Select questions for custom report or choose to generate a complete report

The system processes and visualizes responses

Download a professional Word report with charts and summaries

✅ Requirements
Python 3.8+

Flask

Pandas

Openpyxl

python-docx

matplotlib/seaborn
